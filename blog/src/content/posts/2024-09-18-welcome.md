## 欢迎 👋

这是一篇示例文章，用来展示自动化博客系统的功能。

### 系统特性

这个自动化博客系统具有以下特点：

1. **AI 驱动生成**：使用 Claude AI 自动生成高质量内容
2. **SEO 优化**：自动生成元标签和关键词
3. **完全自主**：所有代码和数据都在你的控制之下
4. **易于使用**：简单的命令即可生成和发布内容

### 如何开始

要生成你自己的文章，只需运行：

```bash
npm run generate
```

系统会根据你在 `.env` 文件中设置的主题自动生成文章。

### 自定义配置

你可以通过编辑 `.env` 文件来自定义：

- 内容主题
- 文章语言
- 生成数量
- 作者信息

### 部署到线上

这个博客可以轻松部署到：

- **Vercel** - 推荐，完全免费
- **Netlify** - 也很好用，免费
- **GitHub Pages** - 传统方案

查看 README.md 了解详细的部署步骤。
