## 发布执行边界

执行入口为 `npm run publish:next`，计划在 `content/publication-plan.json`，真实发布记录在 `content/publication-history.json`。`.github/workflows/auto-publish.yml` 每周一、二、四 UTC 01:00 运行（北京时间 09:00）；GitHub 调度可能有延迟。工作流读取最新 main，消费显式队列，更新 `pubDate` 与 `draft: false`，构建成功后提交文章和发布记录，触发现有 Vercel 部署。

队列耗尽后每次调用现有 Claude 中转 API 生成一篇，复用已保存品牌事实与官网产品图片，不执行资料过期重核门槛，也不等待逐篇审批。保留英文、猫主题、来源链接及图片存在性检查。历史草稿不会被随机发布。API 或构建失败时不会提交发布变更，GitHub Actions 留存错误日志。

本聊天另设周一、二、四北京时间 10:30 的漏发补跑任务，仅在远端没有当天发布记录且没有正在运行的任务时，触发现有云端工作流。日常发布以 GitHub 定时任务为主；本地聊天补跑属于辅助，不是电脑关机时的发布依赖。正常不额外通知，仅失败需要处理时提醒。
